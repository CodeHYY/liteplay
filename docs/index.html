English

  • Plays local videos, http(s) links, HLS (m3u8), DASH, with external .srt / .vtt subtitles and resume playback.
  • Tiny: 1.9 MB APK, Android 8.0+. Built on Media3/ExoPlayer.
  • Privacy: only the INTERNET permission (used when you play a network URL). No analytics/tracking SDK, no account, no upload. Local files are opened through the system file picker.
  • Free: 0.25×–2× speed, 5 resume entries, a short 5-second ad every 3rd playback + a banner. VIP (one-time offline license key): no ads, picture-in-picture, up to 4× speed, 200 resume entries.
  • LitePlay is only a player: it ships with no media content. Play only what you have the right to watch.
